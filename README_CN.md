# OneShot Android

[简体中文](README_CN.md) | [English](README.md)

## 核心功能

- **本地文件加密**：选择文件并生成 `.oneshot` 加密文件。
- **密码保护**：使用密码加密和解密文件。
- **文本预览**：在应用内查看 UTF-8 文本。
- **图片预览**：在应用内查看图片，并自动缩放以降低内存占用。
- **文件有效期**：支持 1 小时、24 小时、7 天和永不过期。
- **一次性使用**：成功打开后记录文件指纹，阻止同一文件在本机再次打开。
- **自动清理**：退出预览、应用进入后台或下次启动时清理临时明文文件。
- **隐私保护**：启用 Android `FLAG_SECURE`，限制截图和最近任务预览。
- **离线使用**：无需注册账户或连接服务器。

## 加密方案

| 项目 | 方案 |
|---|---|
| 对称加密 | AES-256-GCM |
| 密钥派生 | PBKDF2-HMAC-SHA256 |
| 迭代次数 | 310,000 次 |
| 密钥长度 | 256 bit |
| Salt | 随机生成，16 字节 |
| IV | 随机生成，12 字节 |
| GCM 认证标签 | 128 bit |

`ONESHOT2` 文件格式会使用 GCM AAD 对文件头元数据进行认证，其中包括有效期信息。

同时保留对旧版 `ONESHOT1` 文件的解密兼容性。

## 文件有效期与一次性使用

- 有效期从文件加密完成时开始计算。
- 解密前检查文件是否过期。
- 只有成功解密后才写入本机使用记录。
- 使用 SHA-256 计算文件指纹，可识别改名或移动后的同一文件。

## 支持范围

- 最低 Android 版本：Android 8.0（API 26）。
- 文本预览上限：2 MB。
- 图片预览时自动缩放。
- 支持加密任意文件，但并非所有文件类型都支持应用内预览。
